Scenario 1  ·  ● Live & tested
Create SLA Draft
ClickUp → PandaDoc.

The moment a task in the Contracts & SLAs list is marked Draft, four steps run automatically:

1

Watch the list

Make watches the Contracts & SLAs list for new or updated tasks and reads the task's fields.

2

Gate on readiness

It only proceeds when Doc Status = Draft and no PandaDoc link exists yet — the idempotency guard that stops it from ever double-generating.

3

Build the document

PandaDoc creates a draft on the template matched to the SLA Type, named for the client and priced for their tier. It's created as a draft — nothing sends on its own; you confirm the signer and hit send.

4

Link it back

The new PandaDoc link is written onto the ClickUp task's PandaDoc Link field, so the agreement lives right next to the work.
