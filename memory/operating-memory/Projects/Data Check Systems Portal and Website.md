# Data Check Systems Portal and Website

## Summary

Data Check Systems is an ImpactWorks client project covering both a main website redesign/realignment and customer portal improvements.

## Portfolio-safe version

Use this for public-facing portfolio/proposal language:

> Redesigned and improved the Data Check Systems web presence and customer portal experience, including responsive site structure, conversion-focused content, lead capture, report-ordering flows, dashboard improvements, navigation cleanup, and portal search/report usability.

## Confirmed components

- Main website redesign and realignment for `https://datachecksystems.com/`.
- Conversion-focused web strategy.
- Responsive website design for desktop, tablet, and mobile.
- CMS content loading and formatting.
- Homepage, services, products, about, and contact content.
- Forms for contact, customer feedback, and report ordering.
- Blog/news setup.
- Homepage hero/slideshow.
- Google Analytics and Google Webmaster Tools setup.
- SEO: competitor benchmark, keyword research, titles, meta descriptions, copy optimization, image optimization, XML sitemap, robots.txt, Google Business Profile optimization.
- Portal work:
  - Login redirection cleanup.
  - Header/navigation consistency.
  - Better-looking functional dashboard.
  - Dynamic report blocks based on report/project status.
  - Search feature exploration for reports.
  - Uploaded documents/report page usability.
- Revision evidence:
  - Fixed call/email links.
  - Fixed search/button behavior.
  - Adjusted browse report/order report links.
  - Updated scrolling customer list behavior.
  - Required fields and form layout corrections.
  - Copy revisions.

## Platform / tech

- WordPress.
- Client portal plugin / portal application.
- CMS.
- Google Analytics.
- Google Webmaster Tools.
- Google Business Profile.
