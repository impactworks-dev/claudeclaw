# VascuScreen Medical Device Website and AI Portal

## Summary

VascuScreen is an ImpactWorks project combining a medical/wellness website redesign/build with a full-stack health intelligence portal for vascular screening results, patient/provider workflows, and AI-assisted report interpretation.

## Portfolio-safe version

Use this for public-facing portfolio/proposal language:

> Built and presented a full-stack VascuScreen health intelligence portal concept for vascular screening workflows, combining patient report interpretation, provider dashboards, AI chat/RAG support, report ingestion, and a roadmap toward API-connected medical device data.

## Confirmed components

- Premium website redesign and build for VascuScreen.
- Member login page.
- Medical/wellness visual direction with high-impact interaction and motion graphics.
- WordPress + Elementor marketing-site implementation scope.
- Full-stack health intelligence portal.
- Patient portal experience.
- Provider dashboard for monitoring patient populations.
- AI-powered patient chat.
- Report interpretation for dense clinical vascular screening PDFs.
- Agent trained on full-stack documentation for the screening units.
- PDF/device-output interpretation and scoring.
- API integration discussion for automating VascuScreen data ingestion.
- Roadmap:
  - Phase 1: real AI chat using Claude with RAG retrieval from the knowledge base.
  - Phase 2: provider upload flow for raw device JSON that auto-generates scored reports.
  - Phase 3: Expo mobile companion app for providers to review patients/results on the go.

## Platform / tech

- React.
- Express.
- PostgreSQL.
- Drizzle ORM.
- Claude with RAG retrieval.
- WordPress + Elementor for marketing website.
- Expo mobile app roadmap.
