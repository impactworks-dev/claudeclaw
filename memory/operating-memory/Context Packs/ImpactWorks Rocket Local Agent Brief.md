# ImpactWorks Rocket Local Agent Brief

## Use this when

Use this context pack when an agent needs high-level operating context for ImpactWorks, Rocket Local, Dante, ClickUp Brain, Unabyss, G-Brain, Obsidian, portfolio work, proposals, or client/project continuity.

## Essential context

- Dante Crescenzi is the human operator, founder, AI builder, and strategy lead.
- ImpactWorks is the executive strategy, AI workforce, transformation, AuditFlow, and automation architecture brand.
- Rocket Local is the local growth, implementation, Launchpad, Campaigns, CRM AI, local SEO, and SMB execution brand.
- Dante is the leadership bridge between both brands.
- ClickUp is the operational system of record for tasks, statuses, approvals, project execution, and CRM workflow.
- Obsidian is the private canonical knowledge vault.
- Unabyss is the cross-agent context layer.
- G-Brain is a queryable brain/context runtime that should consume compact source-backed context packs.
- Codex/Nikki is the broader workbench: compiler, validator, browser/file/tool operator, builder, and updater.

## Current operating stance

- Keep ImpactWorks and Rocket Local distinct.
- Do not duplicate brand content across channels.
- Verify live mutable state before making consequential claims.
- Prefer source-backed summaries over raw dumps.
- Preserve approval gates for external writes, broad connector ingestion, client-facing communication, CRM writes, and public profile edits.
- Use ClickUp for execution, not as the full brain.

## Brand and project positioning

- ImpactWorks: modern, trustworthy, minimal, creative, AI strategy and automation for ambitious brands.
- Rocket Local: pragmatic local growth implementation for SMBs.
- AuditFlow: ImpactWorks diagnostic/commercial wedge and first MCP-style product slice.
- ClickUp Super Agents: internal operating agents, not a separate platform.

## Agent routing

- Use Codex/Nikki for browser/file/system work, generated assets, code, validation, multi-source compilation, and public-site/public-profile operations.
- Use ClickUp Brain/Nikki for ClickUp-native project records, task updates, open loops, portfolio tracking, and execution memory.
- Use G-Brain to retrieve compact source-backed context packs before agent work.
- Use Obsidian for canonical private notes and sensitive source-backed material.
- Use Unabyss to unify durable context across agents and tools.

## Safety rules

- Do not invent facts.
- Separate confirmed facts from assumptions.
- Mark missing info as `Needs confirmation`.
- Treat memory as possibly stale when it concerns live state.
- Do not perform external writes, sends, public profile changes, CRM writes, billing changes, or destructive operations without explicit approval.
- Do not copy private or sensitive raw source material into public repos or general context packs.
